# Іконки бірж

Ця папка містить іконки бірж для відображення в інтерфейсі.

## Формат файлів

- Назва файлу: `[назва_біржі].png` (наприклад: `binance.png`)
- Розмір: рекомендується 24x24 пікселі або більше (буде автоматично масштабуватися)
- Формат: PNG з прозорим фоном

## Приклад

Для Binance:
- Файл: `binance.png`
- Розмір: 24x24 або більше
- Формат: PNG

## Де знайти іконки

Іконки бірж можна знайти на офіційних сайтах бірж або використовувати стандартні логотипи.
