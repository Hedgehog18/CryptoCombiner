# CryptoCombiner

Desktop-застосунок на Python для роботи з криптовалютами: портфель, угоди, графіки, сигнали та автоматизація.

## 📋 Опис

CryptoCombiner — це комплексний інструмент для трейдерів та інвесторів у криптовалютах. Застосунок надає зручний інтерфейс для моніторингу портфеля, аналітики ринку та управління угодами.

## 🔧 Технології

- **Python 3.12** — мова програмування
- **PySide6** — графічний інтерфейс на базі Qt
- **QSettings** — збереження налаштувань та стану програми

## ✨ Поточні можливості

- 🖥️ Нативний графічний інтерфейс для Windows
- 📑 Розділи: Огляд, Trade, Налаштування
- 🔖 Система вкладок для кожного розділу
- 💾 Автоматичне збереження стану між запусками
- 🎨 Темна тема інтерфейсу
- ⚙️ Розділ налаштувань з вкладкою "Акаунт"

## 📦 Встановлення

### Вимоги

- Python 3.12 або новіша версія
- Windows 10/11

### Кроки встановлення

1. Клонуйте репозиторій або завантажте проект:
   ```bash
   git clone <repository-url>
   cd CryptoCombiner
   ```

2. Створіть віртуальне середовище (рекомендовано):
   ```bash
   python -m venv venv
   venv\Scripts\activate
   ```

3. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```

## ▶️ Запуск

### Варіант 1: Через Python
```bash
python main.py
```

### Варіант 2: Через batch-файл (Windows)
Подвійний клік на файл `run.bat`

### Варіант 3: Через PowerShell скрипт
```powershell
.\run.ps1
```

## 📁 Структура проекту

```
CryptoCombiner/
├── main.py                 # Точка входу програми
├── requirements.txt        # Залежності проекту
├── run.bat                 # Скрипт швидкого запуску (Windows)
├── run.ps1                 # PowerShell скрипт запуску
│
├── ui/                     # Модуль інтерфейсу
│   ├── main_window.py      # Головне вікно програми

│   ├── theme.py            # Темна тема інтерфейсу
│   └── pages/              # Сторінки розділів
│       ├── base_page.py    # Базовий клас сторінки
│       └── dashboard.py    # Сторінка дашборду
│
└── core/                   # Основна логіка (в розробці)

```

## 🛠️ Розробка

### Збірка .exe файлу

Для створення standalone виконуваного файлу використовуйте PyInstaller:

```bash
pyinstaller main.py --windowed --onefile
```

Результат буде в папці `dist/CryptoCombiner/`.
