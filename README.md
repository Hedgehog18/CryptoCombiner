# CryptoCombiner

Desktop-застосунок на Python для роботи з криптовалютами:
портфель, угоди, графіки, сигнали та автоматизація.

## 🔧 Технології
- Python 3.12
- PySide6 (Qt)
- QSettings (збереження стану)
- Git / GitHub

## ✨ Поточний стан (v0.0)
- Нативне вікно Windows
- Sidebar + вкладки
- Збереження стану між запусками
- Темна тема
- Debug-рамки для верстки
